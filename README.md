# Monti Atención

Sistema web de atención por QR para Monti Bar de Pastas.

## Objetivo
- QR único por mesa.
- Solicitudes de mozo, cuenta y pedidos adicionales con mensaje libre.
- Reclamos, sugerencias y felicitaciones dirigidos a gerencia.
- Panel de barra y panel privado de gerencia (pendientes de autenticación).

## Estado
Prototipo inicial. No usar con clientes reales hasta configurar Firebase, reglas de seguridad y autenticación.

## Publicación
La página estática puede publicarse con GitHub Pages. La sincronización entre dispositivos requiere configurar Firebase.
